# Симулятор магазина с корзиной покупок

Итоговый проект по теме "Алгоритмы сортировки и структуры данных".

## 📌 Возможности проекта

1. **Каталог товаров (Модуль Product):** товары с названием, категорией, ценой, весом и описанием.
2. **Корзина (Модуль Cart):** добавление/удаление товаров, просмотр, подсчет итоговой стоимости с учетом скидки.
3. **Алгоритмы сортировки:** реализованы Bubble Sort, Insertion Sort, Quick Sort и Merge Sort. Сортировка возможна по цене, весу или категории, по возрастанию или убыванию.
4. **Визуализация:** вывод процесса сортировки (количество перестановок) и красивый табличный вывод в консоль.

## 🚀 Как запустить

1. Убедитесь, что у вас установлен Python 3.
2. Скачайте файл `shop.py`.
3. Откройте терминал (командную строку) в папке с файлом.
4. Выполните команду:
   ```bash
   python shop.py
